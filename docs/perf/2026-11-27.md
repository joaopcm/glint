## setup

- Mac16,8 (Apple M4 Pro), macOS 27.2.1
- displays: 3008x1692 @ 120 Hz. 5 visible windows
- normal desktop load, not a clean boot
- Lunetta: Release build of `main` at 690dc68, `/Users/jopcmelo/Applications/Lunetta.app`, default settings, area hotkey pinned to `⇧⌘2` and freeze screen pinned off
- CleanShot X: 5.0.2 (`com.getcleanshot.app-setapp`), the owner's settings except freeze screen pinned off, area hotkey its default `⇧⌘4`

## trigger to overlay on screen

10 presses per app, 2 s apart, Esc after each. both apps get the same input: `CGEvent` key events from a `.hidSystemState` source posted at the HID event tap, modifiers as separate presses, through each app's own area hotkey. right before it, the app's on-screen windows are snapshotted. t0 is taken right before the main key-down, then `CGWindowListCopyWindowInfo` is polled every 250 µs. t1 is the first poll with an on-screen window from the app that covers a whole display, on any layer, and wasn't in the snapshot. after Esc, the same windows have to leave the screen before the next press.

| app | trigger | median | min | max |
| --- | --- | --- | --- | --- |
| Lunetta area | `⇧⌘2` hotkey | 34.7 ms | 24.0 ms | 87.6 ms |
| CleanShot X area | `⇧⌘4` hotkey | 89.2 ms | 77.9 ms | 158.4 ms |

## what's off about this comparison

- the number is trigger to window-server order-in, not to photons. display scan-out is left out for both apps
- the hotkeys are synthetic events, not a physical keyboard. both apps take the same path, so the comparison holds, but the absolute numbers leave out the keyboard and HID driver
- both run with freeze screen off. that way CleanShot X shows nothing you can see except the cursor: its full-display window sits at layer -2147483600, behind other apps' windows. so for CleanShot X, t1 is when it enters area capture, not when something is drawn. with freeze on, that window orders in in the same poll as its visible overlay (3 of 3 presses checked), so it's the same moment either way
- app size counts what each bundle ships. CleanShot X's Setapp build also needs the Setapp agent, which isn't counted
